# 魂の生き直しコーチング LP

GitHub Pages にアップロードして公開できる構成です。

## ファイル

- `index.html` — LP本体
- `style.css` — デザイン・レスポンシブ対応
- `images/hero.png` — ヘッダー画像

## 公開方法

GitHubのリポジトリに3点をアップロードし、Settings → Pages から
`Deploy from a branch` / `main` / `/(root)` を選択してください。

申し込みボタンは、指定されたGoogleフォームへリンクしています。

※文章・価格・キャンセル規定などは公開前に最終確認してください。
